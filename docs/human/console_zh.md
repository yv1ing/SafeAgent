# 控制台

[English](console.md)

控制台面向运维人员，用于查看进入网关的流量、每次调用的处理过程，以及这次调用所依据的策略决定。

## 组织方式

所有内容按项目组织。项目的模型路由、脱敏规则、策略、访问密钥和审计记录均属于项目，相关设置也位于项目内部。

未进入项目时，侧边栏提供监控和项目；管理员还可看到渠道、用户和日志。进入项目后，侧边栏提供概览、调用记录、会话、风险、操作记录、策略、数据脱敏、Agent 密钥、模型路由、成员和设置。顶栏包含项目切换、面包屑、语言与主题设置以及账号菜单。

## 通用交互

列表采用统一的筛选和分页方式。调用记录页面将筛选条件写入地址栏，因此筛选后的视图可以刷新或分享。宽屏下调用详情显示在列表旁边，窄屏下以抽屉形式打开。

新建和编辑操作使用对话框；项目设置、渠道设置和策略编辑器直接在页面内修改。策略编辑器提供保存和放弃；项目与渠道设置通过保存按钮提交修改。删除等操作需要再次确认。密钥和密码仅显示一次，并提供复制按钮。

界面只显示当前账号有权执行的操作。项目成员可以管理路由、非阻断类脱敏规则、仅记录的策略规则和 Agent 密钥；信任级别和非默认角色仅管理员可以设置。管理员还负责渠道、用户、全局日志、项目的创建与删除、成员、阻断类策略与脱敏规则、策略恢复、决策模型，以及项目设置中的保留天数和限额。

渠道还可以设置默认输出上限，以及允许转发给上游的客户端请求头；项目设置提供项目级默认值。这些上限用于发往 Anthropic Messages 上游的调用，因为该协议要求必须给出上限：客户端自己声明的值优先，其次是路由目标覆盖值（通过 API 设置）、渠道默认值和项目默认值，最后才使用网关兜底值。其他协议未给出上限时，由服务商决定。

## 调用

调用记录页面集中展示指标、在线决定、对话内容、上游尝试和异步分析。原始事件仅管理员可见。

在线决定说明某次请求或工具调用是被哪条规则、哪个模型答案放行或阻断的。在线路径仅保存决定；诊断产生的发现和关系显示在分析区域。

每条分析显示结论、覆盖情况、检测器与分类法版本、决策模型的答案（如有）、发现和关系。发现包含检测码、来源、去向、三个分类维度、严重度、置信度、检测器和证据。失败的分析保留错误和覆盖状态。页面可以触发重新分析；新结果与旧结果并列保存，输入、检测器和分类目录版本一致时可以比较。

## 风险

项目风险页展示风险来源、失败模式、现实危害和严重度的分布，以及高频发现和发现或关系数量最多的 Agent。选择某个 Agent 后，页面列出所选时间窗内的关系边：哪段外部内容进入了哪个工具调用，关系是值复用还是指令跟随。

关系边描述单次调用内部的关系，不表示前一次调用导致了后一次。页面按 Agent 密钥聚合展示。

## 策略与脱敏

策略页面编辑一张有序的 CEL 规则表。编辑器在保存前校验，保存时在一个事务内启用新版本。历史列表显示所有已保存版本、标记当前版本，并为管理员提供恢复操作。恢复旧文档会生成新版本，历史记录不会被改写。

成员可以编辑优先级为 0 的记录规则。管理员写入的阻断规则必须原样保留；成员不能新增、修改或删除这些规则。优先级、版本恢复和决策模型仅管理员可以操作。

数据脱敏页面管理内置检测器、自定义规则，并支持用示例文本测试规则。阻断类脱敏规则会在请求到达服务商之前拒绝请求；只有管理员可以新增、修改或删除这类规则。

## 决策模型

决策模型为可选功能，在项目设置中配置，不属于策略文档。启用后，系统会请它为每条已分析的轨迹给出完整分类标签，并在有副作用的工具调用释放前回答一次授权问题。API Key 仅可写入，界面只显示是否已经保存。

## 界面风格

界面采用接近白色的背景和单一靛蓝强调色，颜色主要用于状态和图表。浅色与深色主题共用配色和焦点样式，键盘焦点在两种主题下均清晰可见。

界面布局紧凑，采用小字号、等宽数字和细边框；仅在需要分组时使用卡片。窄屏下侧边栏变为抽屉，宽表格支持横向滚动。

## 现阶段设计取舍

- **隐藏推理**：控制台只能展示服务商返回的内容。
- **执行证明**：记录下来的工具调用和结果不能证明副作用确实发生。
- **文本脱敏**：图片和音频不经过脱敏引擎。
- **发现需核实**：关系分析和工具能力推断均为启发式方法；未完成的分析记为 `unknown`。
- **响应复核**：响应正文在调用结束后复核，内容到达客户端后无法撤回。
