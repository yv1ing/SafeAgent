# Agent 威胁建模

[English](threat-modeling.md)

Agent 的风险沿一条轨迹展开：内容从某个来源进入，模型决定如何使用，工具据此执行操作。SafeAgent 直接对这条轨迹建模，并让描述与控制台中的证据保持一致。

## 两条研究脉络

三轴分类沿用 AgentDoG，用于标注风险来源、智能体的失败模式以及可能造成的现实危害。SafeAgent 使用这套分类；整条轨迹的标签由可选的决策模型给出，论文中的微调防护模型不在本项目范围内。

策略视角参考 AgentGuard，这是一套面向工具调用智能体的属性访问控制设计。SafeAgent 使用其中的运行时属性（调用方、工具、参数、目标、信任）以及面向工具调用和工具链执行规则的思路。本项目独立实现。两篇论文、许可证以及本项目的差异点记录在 [Agent 开发指南](../agent/papers.md)。

## 来源与去向

一条发现需要回答两个问题：内容来自哪里，可能到达哪里。确定性发现记录来源和去向，并只填写检测码、来源和去向能够支持的三个分类维度。

| 来源               | 含义                       |
| ------------------ | -------------------------- |
| 系统、开发者、用户 | 随请求提供的指令与任务文本 |
| 助手               | 模型输出的文本和工具调用   |
| 工具结果           | 工具返回的内容             |
| 工具描述           | 已声明工具的描述           |
| 分析环境           | 分析器自身报告的覆盖问题   |

去向表示工具调用能够执行的操作：外发数据、执行命令、读取或写入文件、访问凭据、付款、没有可观测副作用，或者无法判断。网关根据工具名称、参数和目标推断去向。该结果由推断得出，必要时可人工核实。

关系用于连接一次调用内的外部内容与后续有副作用的工具调用。值复用表示内容中的具体片段出现在参数中；指令跟随表示承载注入指令的句子中的片段出现在参数中。仅仅同时出现并不构成关系。关系不跨越调用。

## 两套标签

确定性发现只携带检测器能够确认的维度。维度为空表示尚未确认，不能据此推断该维度没有危害。

可选的决策模型对整条轨迹回答固定问题：是否不安全、风险来自哪里、属于哪种失败模式、可能造成什么危害、严重度如何。答案与发现并列保存，不会改写确定性标签。

## 结论

存在高危发现时，调用结论为 `unsafe`。覆盖完整时，如果决策模型给出概率足够高的不安全答案，调用也会被判为 `unsafe`；服务商另报置信度时，该置信度还需达到阈值。

没有高危发现时，覆盖不完整、只有中等发现、模型答案不确定，或者模型调用失败、预算耗尽，都会使调用成为 `unknown`。

仅当覆盖完整、没有中等或高危发现，且模型未给出不安全答案时，调用才为 `safe`。没有发现本身不足以证明调用安全。

## 在线授权

模型在在线路径上只用于否决。仅当确定性规则放行有副作用的工具调用后，系统才会询问模型。授权概率低且置信度足够时，调用被阻断；超时、返回格式错误或预算耗尽不会改变先前的策略结果。模型可以追加阻断，不能撤销规则决定。

授权问题不包含工具输出、先前的助手文本和先前的工具调用，因此外部内容无法参与决定自己是否被放行。问题包含任务与指令、调用方、已声明工具、非助手文本以及待执行的工具调用。

## 现阶段设计取舍

- **关系匹配**：值复用比指令跟随更可靠，两者都依赖具体片段，改写或语义相近的内容不会形成关系。
- **能力推断**：去向由名称、参数和目标推断，具有误导性的名称可能造成误判。
- **模型不透明**：决策模型给出校准后的答案，不提供理由；其服务提供方也未必将输入视为敌意内容。SafeAgent 隔离不可信文本、在授权问题中排除这些文本、默认使用脱敏视图并记录模型名称，但无法保证模型本身可信。
- **文本脱敏**：图片和音频不经过脱敏引擎。
- **网关范围**：SafeAgent 只能观察经过网关的流量。
